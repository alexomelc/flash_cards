# flash_cards

Spaced-repetition flashcards: decks, cards, daily review, stats.
Built with Next.js 16, Fastify, PostgreSQL and TypeScript.

> Restarted from scratch in November 2026. The first prototype lives in the `v0` branch.

## v1 scope

Sign in · decks · cards · daily review with spaced repetition · optimistic grading ·
basic stats · daily "cards due" email · deployed with a real domain.

Not in v1: AI features, file uploads, sharing decks, admin.
